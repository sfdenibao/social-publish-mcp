# Douyin comments / 抖音评论

See [comment assistant guide](DOUYIN_AUTOREPLY.md) for scope, local configuration, authorization, and privacy boundaries. Tool arguments are defined in [MCP_TOOL_SCHEMAS.json](MCP_TOOL_SCHEMAS.json).

Manual comment preparation and submission are separate operations. A successful preparation or model draft does not send anything. Keep `UNKNOWN_RESULT` tasks for reconciliation instead of creating new IDs to resend.
